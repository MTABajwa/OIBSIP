# Social Engineering Attacks — Research Report

## Project Overview
This repository contains a comprehensive research report on social engineering attacks, focusing on phishing, pretexting, and baiting. The report includes real-world case studies, psychological analysis of why these attacks succeed, prevention recommendations, and a 5-point employee security awareness training checklist.

## Deliverable
- `social_engineering_report.md` — The full research report.

## No Demo Video Required
As per the task guidelines, this is a pure research/report task. No demo video is required for submission.

## References
All sources are cited in the report. Primary references include SANS Institute Reading Room, CISA, Verizon DBIR, and reputable security publications like Wired, Dark Reading, and Krebs on Security.

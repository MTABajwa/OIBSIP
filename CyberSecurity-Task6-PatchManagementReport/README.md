# The Importance of Patch Management — Research Report

## Project Overview
This repository contains a comprehensive research report on the critical role of patch management in cybersecurity. The report covers the vulnerability lifecycle, real-world breaches caused by unpatched systems (WannaCry, Equifax), the consequences of failing to patch, the 5-phase patch management lifecycle, a prioritised 7-step checklist for organisations, and the common challenges that prevent timely patching.

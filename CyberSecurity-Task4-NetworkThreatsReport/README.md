# Common Network Security Threats

## Project Overview
This repository contains a comprehensive research report on common network security threats. The report analyzes four major attack vectors: Denial of Service (DoS/DDoS), Man-in-the-Middle (MITM), IP Spoofing, and DNS Poisoning. For each threat, the report covers the attack mechanics, a documented real-world example, the organizational impact, and actionable mitigation strategies.
